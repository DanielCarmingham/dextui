# Contributing

Thanks for looking. Everything you need is in
[CLAUDE.md](CLAUDE.md#contributing-the-short-version) — start with
**Contributing: the short version** at the top, which covers the toolchain,
what CI runs, the commit convention, what to run before you submit, and a
table pointing at the one section that covers whatever you are changing.

This file deliberately does not repeat any of that. Two copies of a rule
drift, and this project has been bitten by exactly that more than once.

- **Bugs and ideas**: open an issue.
- **Changes**: a pull request is fine, including for small things.
- **User-visible changes**: add an entry to [CHANGELOG.md](CHANGELOG.md) under
  `Unreleased`. That file is what a release *says*, so an entry missing when
  the version is cut is a change nobody is told about.

For what dextui is, how to install it, and what the keys do, see
[README.md](README.md).
